# 登录角色背身文案设计

## 目标

密码处于隐藏状态时，四个角色转身并展示醒目的 A 股研究短句。短句用于增强登录页记忆点，不构成行情预测、收益承诺或交易指令。

## 数据与合规

- 文案和颜色从 `runtime.login_visual` 读取，动画逻辑不内嵌业务文案。
- 配置至少提供八条互不重复的短句和四种十六进制颜色。
- 配置加载时拒绝“一定涨停”“今日涨停”“必涨”“稳赚”“保证收益”“保本”等承诺性表达。
- 推荐使用“涨停待证”“只看证据”“等待确认”“风控优先”等证据导向表达。

## 交互

- 每次进入背身状态，为四个角色抽取四条不同短句。
- 新一组优先排除上一组短句，避免连续重复。
- 每个角色使用不同强调色，并以短促缩放动画出现。
- 文字进行反向旋转补偿，保证角色整体转身后文字仍为正向可读。
- 小屏幕缩小标签和字体，不改变密码交互状态机。

## 验证

- 配置校验覆盖文案数量、唯一性、长度、承诺性禁词和颜色格式。
- 会话接口测试确认词库与色板可以下发。
- 浏览器测试确认同组四条均唯一，连续两组无复用且无脚本错误。
