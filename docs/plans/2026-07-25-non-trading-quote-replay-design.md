# 非交易时段行情回放设计

## 问题

收盘后、周末和休市日刷新时，实时接口可能返回空数据。旧逻辑还会因三分钟缓存 TTL 和“必须是当天”校验拒绝最近交易日的真实收盘快照，最终把页面已有行情覆盖成不可用。

## 数据优先级

1. 数据源带交易日期和时间的实时行情。
2. 数据源返回的最近交易日收盘行情。
3. 完整性校验通过、且未超过配置回放窗口的本地行情快照。
4. 生产 Provider 的真实日线最近收盘价。
5. 全部失败时才返回不可用；不使用样例数据补值。

高优先级候选覆盖低优先级候选，旧快照不得遮蔽实时行情。回放窗口、日线读取数量均由运行配置提供。

## 时间语义

- 行情日期和时间取自数据源，不使用刷新时间冒充成交时间。
- 前端将非实时数据标为“最近交易日收盘”。
- 盘中雷达在连续交易时段仍拒绝上一交易日行情，防止旧价冒充盘中异动。
- 非交易时段允许跟踪池使用最近交易日行情。

## 页面保护

如果一次完整刷新没有取得任何可核验行情，页面保留上一次已经显示的快照，并明确提示“未取得新快照”，不把旧值标为实时，也不清空用户视图。

## 验证

- 周末接受周五收盘行情。
- 超过短时实时 TTL 后仍可回放完整性校验通过的快照。
- 实时报价和缓存同时为空时，使用生产 Provider 的真实日线收盘。
- 未来日期和超过配置期限的快照被拒绝。
- 连续交易时段的盘中雷达不接受上一交易日行情。
- 东方财富快照使用 Provider 时间戳而非本机刷新时间。
